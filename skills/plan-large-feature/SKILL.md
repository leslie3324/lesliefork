# 中大型功能规划

这是规划阶段 Skill。未获得执行确认前，不修改生产代码、不创建实现脚手架、不声称方案已批准。

## 规划要求

- 先检查仓库和现有调用链，区分**事实、决策、假设、阻塞项**；未知内容不要猜。
- 先写用户可感知的结果、范围、约束和非目标。
- 按可验证的垂直切片拆分少量内聚模块，不要只按前端/后端罗列工作。
- 每个模块说明：职责边界、接口、数据所有权、输入/输出、副作用和验证方式。
- 任务使用 `P0`（关键路径）、`P1`（必要配套）、`P2`（加固或后续），并写清任务 ID、范围、前置依赖、验收条件和验证方式。
- 按需补充兼容性、迁移、权限、可观测性、发布、回滚和失败恢复；不相关内容不要展开。

## 输出顺序

1. 目标、范围、非目标和成功标准。
2. 当前事实、决策、假设和阻塞项。
3. 模块设计。
4. 按关键路径排序的任务表。
5. 风险、验证和发布事项。
6. **模块关系**：最后一个主要章节描述入口到结果的数据流、调用依赖、边界、失败处理、可并行部分和关键路径。

结尾必须列出待用户确认的决策、推荐下一步，并说明规划阶段没有修改生产代码。
