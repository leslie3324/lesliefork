# 证据和不确定项

## 证据优先级

1. 已生成的 OpenAPI、Spring REST Docs 片段和已执行测试结果。
2. Controller 路由、DTO、校验注解、全局异常处理器和安全配置。
3. 同一需求范围内的 Service、配置和已有文档。
4. AI 根据代码逻辑做出的推断。

## 输出状态

- **已确认**：来自运行时 OpenAPI、测试结果或明确的接口契约。
- **源码确认**：来自 Controller、DTO、注解、异常处理器或安全配置。
- **待确认**：源码和测试中没有足够证据，必须单独列出。

## 禁止猜测

没有证据时，不得自行确定：

- 接口路径、HTTP 方法和认证 Header
- 请求或响应字段、字段类型和必填性
- 错误码、错误消息和状态码
- 分页结构、幂等规则和业务前置条件
- Postman 业务断言

示例值可以生成，但必须标注为示例，不得冒充真实生产数据或凭据。
