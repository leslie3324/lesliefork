# Comein 数据库接入

职责：集中维护 Comein 数据库接入约定；各 Skill 引用本说明，不另维护副本。不保存密码或业务数据。

## 已确认方式

用户使用 DBeaver 已有连接操作测试 MySQL。MVP 沿用该方式，不安装新客户端，不导出连接配置或读取保存的密码；连接可用性和权限尚未验证。

每次提供测试连接名称、目标库和本次 SQL 或变更需求。测试连接对应的主机、端口及目标库尚未确认；首次操作时通过非敏感连接信息核对实际目标，并由用户确认它属于测试环境，不凭连接名称或颜色判断。

最近一次 DBeaver 界面检查显示 `comein-test` 的客户端只读开关已开启（菜单项为 `Make comein-test not read-only`）。这是客户端保护，不代表数据库账号只有只读权限；每次操作仍须重新检查。需要写入时不得因 SQL 已获批准就自行关闭该开关，须另行征得用户明确同意；获准临时关闭后，操作结束应恢复只读。

## DBeaver 操作

- 需要 computer use 的桌面能力，浏览器控制不能代替；工具缺失、需登录或权限不足时停止，请用户处理，不自行绕过。
- 检查活动 SQL 编辑器实际绑定的连接和库，只读查看版本及本次相关结构；不覆盖已有 SQL，不改连接配置，不保存或复用凭据。
- 执行前查看自动提交状态及已有事务；已有事务未结束或状态不明时暂停，请用户处理，不能擅自提交或回滚。DDL 即使关闭自动提交也可能隐式提交。
- 每次仅选中本次批准的完整语句并核对执行命令的作用范围，不使用执行整个脚本；结果不明先只读核对实际状态，部分失败停止，不整批重跑。
- 如本次批准的 DML 尚未提交，提交或回滚另行确认；不得提交用户其他待处理编辑或事务。验证本次表结构或数据，并明确提交状态，不以“执行完成”代替验证成功。

SQL 遵循 Comein `AGENTS.md` 的 DDL 规范；正式环境本版只准备方案，不执行。执行记录和脱敏证据供发布流程引用，不自动创建或暂存一次性 SQL、数据库导出或发布文档。
