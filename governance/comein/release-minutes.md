# Comein 发版纪要

## 本地材料

- 唯一格式源是 [模板](templates/release-checklist.md)，参考公司周发版纪要；不固定周文档 URL，也不复制历史 SQL、配置值或执行结果。
- 模板是一份环境分区：在 `docs/<功能分支>/release-checklist.md` 中按需初始化测试/生产两区，后续局部更新，不重建整份文件；可反复修改，用户审核后定稿。原有通用材料按目标环境逐项迁移，执行记录不能丢失。
- 每个条目带需求编号和归属服务。有负责人列写 `姚文宇（ywy）`；其他内容用 `【ywy｜需求编号】`，SQL/配置的说明或注释同时标明服务及执行时机。
- 没有变化且已确认的项目写“否（ywy｜需求编号：本需求无此项变更）”，不留空；未知写待确认，计划写待执行。勾选项只按实际证据完成，定稿不表示部署完成。
- 模板中的发版信息和检查清单是本需求的本地记录，不代表有权修改公共周文档对应区域。敏感配置只指向受控来源，不将真实凭据放入材料或同步预览。

## 审核后同步

1. 用户须明确授权目标文档、需求和测试/生产范围；“定稿”不授权上传。先读取目标，用负责人、需求编号、服务、条目类型联合定位；已有 ywy 条目增改，缺少则新增，不整段追加副本。多条同键再核对对象（如表名/配置名/接口/SQL 文件）；仍不唯一就停。
2. 只有同一行/块或明确独立的归属说明能证明所有权时才能更新。历史 `ywy` / `姚文宇` 标记须核对需求和服务，不能按邻近位置、aichat 服务名或单独关键词猜。混有他人内容的块不整体替换；归属不明先问用户。
3. 给用户看逐项增改差异、目标 URL、环境及本地待同步内容摘要（SHA-256，不含本地审核/同步记录），确认后执行；已授权明确内容和范围且预览无新增取舍时不重复询问。未执行项仍写待执行，生产不能沿用测试 MR。
4. 仅增改本需求的 ywy 行、单元格文本或独立块。禁止整篇/整节/整张共享表覆盖、全局字符串替换、修改他人行块、公共发版信息及全局检查清单；本需求“否”不能覆盖其他人的“是”或配置。
5. 写前重读最新目标并核对摘要、所有权、块 ID 和预览；远端目标或本地内容变了就重新出差异确认，远端其他区域变化也要刷新快照。每批带读取时的版本；版本参数不是并发锁，存在并发编辑或无法确认安全时停止写入，不用 `-1` 或盲目改成最新版本绕过。
6. 每批后回读实际内容和新版本，再处理下一批；核对 ywy 条目、条目数及他人行块/公共区域内容与快照一致。插入或替换后重新取 ID，不复用失效 ID；完全一致才记同步成功。超时、部分成功或异常先读回，保留操作标识，只补已确认未落地项，不整批重试、整篇回滚或恢复他人的旧内容。

局部文本更新、插行及重复同步已在独立测试文档真实验证，见 [验收记录](../../evals/release-checklist.md)。公共文档同步仍需逐次明确授权，并确认目标 ywy 区域在同步期间无人编辑；无法确认就只给预览。写前重读与写后核对不能消除两次请求间的竞态，不承诺并发安全。Skill 不提供权限，也不擅自创建测试文档、登录或扩展授权。

## 飞书局部编辑

优先使用已配置的 `lark-doc` / `lark-cli --as user`，读取与修改前按该 Skill 阅读当前版本的操作指引。关键词结果可能只是表格切片，不能当完整共享表回写。

- 独立 ywy 块：使用明确 block ID 的局部编辑，保留样式和引用；禁止 `overwrite` 及整张表 `block_replace`。
- 表格已有行：取完整行的归属信息和各单元格下的文本 block，仅改 owned 文本，不替换 Table/TableCell。
- 表格缺行：原生 `insert_table_row` 只插入新行，回读新 cell 和子块后填入内容；填充失败保留该行的定位和操作标识，不再插一遍。新增独立 SQL/配置块也需先标明 ywy、需求、服务、执行时机。
- Shortcut 不支持的操作可用 `lark-cli api`，先核对官方规范和 dry-run；不能手写凭据或猜路径。原生请求使用每次操作的 `client_token` 作幂等标识，并带 `document_revision_id`；批量更新同一 block 不重复，最多 200 个请求。
- `ok: true` 还要核对业务结果和回读；dry-run 只证明请求预览，不证明权限、实际写入、并发安全或幂等性。

已核对的官方接口（使用时再核对当前规范）：

- [更新块](https://open.feishu.cn/document/server-docs/docs/docs/docx-v1/document-block/patch.md)：`PATCH /open-apis/docx/v1/documents/:document_id/blocks/:block_id`，支持 `update_text_elements` 和 `insert_table_row`。
- [批量更新块](https://open.feishu.cn/document/server-docs/docs/docs/docx-v1/document-block/batch_update.md)：`PATCH /open-apis/docx/v1/documents/:document_id/blocks/batch_update`。
- [获取块](https://open.feishu.cn/document/server-docs/docs/docs/docx-v1/document-block/get.md)：`GET /open-apis/docx/v1/documents/:document_id/blocks/:block_id`。

读取需查看新版文档权限，写入需编辑新版文档权限，且用户拥有目标文档实际权限。实测旧版本请求仍被接受，不能把 `document_revision_id` 当成严格的 compare-and-swap；本次未验证不同用户同时编辑，存在共编竞争风险。
