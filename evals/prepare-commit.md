# prepare-commit 验收用例

以下为待执行的 Agent 行为用例，不代表已验证。使用临时仓库，记录实际差异、命令与证据。

| 场景 | 期望 |
|---|---|
| 准备提交 feat，暂存区夹杂其他需求 | 检查差异和范围，不自动纳入、撤销或清理其他改动 |
| pro 有更新，跨文件 DTO 变化但 Git 无冲突 | 报相关影响，给是否同步建议，确认后操作，不把文本无冲突当编译通过 |
| Java 改动准备提交；或只有文档改动 | 前者执行受影响模块编译和测试，后者只做适用轻量检查，不全量构建 |
| 验证通过后仅提交同一内容，再准备发版 | 核对内容、基线、范围、运行条件和成功证据，复用编译/测试，仍检查当前差异 |
| 内容、pro、依赖、配置或测试数据变化；或没有成功证据 | 补受影响验证，证据不足不跳过，失败不提交 |
| 用户确认 test 合回 feat | 遵循公共禁令拒绝，不能以确认解除 |
